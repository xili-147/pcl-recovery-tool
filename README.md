# PCL 一键恢复工具

> 回退 PCL2 到 2.14.0.0 旧版本，恢复 Minecraft 下载功能

## 背景

2026年10月20日，国内多款 Minecraft 第三方启动器（PCL2、HMCL 等）因举报事件被迫关停 MC 本体下载功能。PCL2 新版本（2.99+）不再提供 MC 下载，但旧版本 2.14.0.0 仍可正常使用。

本工具帮助用户一键回退到 2.14.0.0，并通过只读保护防止 PCL 自动更新覆盖。

## 功能

- 🔍 **自动检测** PCL 安装位置（常见路径 / 桌面快捷方式 / 运行中进程）
- 📥 **多源下载** GitHub + 镜像源，自动切换
- 💾 **自动备份** 恢复前备份当前版本，可随时还原
- 🔒 **只读保护** 防止 PCL 自动更新覆盖回新版
- 🎨 **图形界面** 简洁易用，一键操作

## 使用方法

1. 下载并解压本工具
2. 双击 `PCL恢复工具.bat`
3. 确认检测到的 PCL 路径正确（或手动浏览选择）
4. 点击「一键恢复旧版本」
5. 等待完成，打开 PCL 即可

## 系统要求

- Windows 10 或更高版本
- PowerShell 5.0+
- 网络连接（用于下载旧版本文件）

## 常见问题

**Q: 恢复后 PCL 还是提示更新？**
A: 本工具会自动将 exe 设为只读，PCL 无法自我更新。如果仍弹出提示，直接关闭即可。

**Q: 下载失败怎么办？**
A: 本工具内置 3 个下载源（GitHub + 2 个镜像）。如果全部失败，请检查网络或使用 VPN。

**Q: 恢复后想回到新版本？**
A: 在 PCL 安装目录找到文件名含 `backup` 的 exe，删除只读属性后改回原名即可。

**Q: 杀毒软件报毒？**
A: 本工具为 PowerShell 脚本，部分杀软可能误报。源码完全开源，可自行审查。
