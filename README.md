# PCL 一键恢复工具

> 回退 PCL2 到 2.14.0.0 旧版本，恢复 Minecraft 下载功能
>
> **更新策略：正常更新照常放行，只有"砍掉 MC 下载"的坏更新会被自动撤回**

## 背景

2026年10月20日，国内多款 Minecraft 第三方启动器（PCL2、HMCL 等）因举报事件被迫关停 MC 本体下载功能。PCL2 新版本（2.99+）不再提供 MC 下载，但旧版本 2.14.0.0 仍可正常使用。

本工具帮助用户一键回退到 2.14.0.0，并通过「更新守卫」防止坏更新再次生效。

## 功能

- 🔍 **自动检测** PCL 安装位置（常见路径 / 桌面快捷方式 / 运行中进程）
- 📥 **多源下载** GitHub + 镜像源，自动切换
- 💾 **自动备份** 恢复前备份当前版本，可随时还原
- 🛡️ **更新守卫（v1.1）**
  - 正常更新**照常放行**——PCL 自动更新不受影响
  - 砍掉 MC 下载的坏更新（≥2.99）**自动撤回**到备份版本
  - 可选：开机自动守卫（登录时静默检查，右下角气泡提醒）
  - 可选：完全锁定更新（禁止一切更新，最保险）
- 🎨 **图形界面** 简洁易用，一键操作

## 使用方法

1. 下载并解压本工具
2. 双击 `PCL恢复工具.bat`
3. 确认检测到的 PCL 路径正确（或手动浏览选择）
4. 点击「一键恢复旧版本」
5. （推荐）勾选「开机自动守卫」

之后 PCL 可以正常使用：正常更新照常安装；如果装上了砍掉 MC 下载的坏版本，守卫会自动撤回到备份版本并弹出提示。

## 系统要求

- Windows 10 或更高版本
- PowerShell 5.0+
- 网络连接（用于下载旧版本文件）

## 文件说明

| 文件 | 说明 |
|------|------|
| `PCL恢复工具.bat` | 启动器（双击运行） |
| `PCL恢复工具.ps1` | 主程序（PowerShell WinForms GUI） |

配置和守卫日志存在 `%APPDATA%\PCLGuard\`（按机器保存，不在压缩包内）。

## 更新守卫工作原理

1. 守卫读取 PCL 主程序的版本号
2. 版本 **< 2.99** → 视为正常更新，放行不动
3. 版本 **≥ 2.99**（砍掉 MC 下载的版本）→ 自动从 `*.backup_*` 备份还原，并气泡提示
4. 没有备份时，提示打开工具点「一键恢复旧版本」

坏版本判定规则在 `PCL恢复工具.ps1` 顶部 `$BadVersionMin` 可自行调整。

## 常见问题

**Q: 恢复后 PCL 提示更新怎么办？**
A: 可以放心点更新试试——如果是坏版本（≥2.99），守卫会自动撤回。不想折腾的话，勾选「完全锁定更新」。

**Q: 下载失败怎么办？**
A: 本工具内置 3 个下载源（GitHub + 2 个镜像）。如果全部失败，请检查网络或使用 VPN。

**Q: 恢复后想手动回到新版本？**
A: 在 PCL 安装目录找到文件名含 `backup` 的 exe，改回原名即可（守卫会再次撤回 ≥2.99 的版本，可先关闭自动守卫）。

**Q: 杀毒软件报毒？**
A: 本工具为 PowerShell 脚本，部分杀软可能误报。源码完全开源，可自行审查。
